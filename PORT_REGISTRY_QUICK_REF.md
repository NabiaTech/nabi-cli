# Nabi Port Registry - Quick Reference

## File Locations

```
CONFIG (Source of Truth)
  ~/.config/nabi/ports/
    ├─ _ranges.toml           ← Port range definitions
    ├─ infrastructure.toml    ← Loki, Grafana (3000-3999)
    ├─ federation_core.toml   ← MCP, coordination (8000-8099)
    ├─ applications.toml      ← Vigil, etc (8100-8199)
    ├─ storage.toml           ← SurrealDB, Redis (8200-8299)
    └─ communication.toml     ← OAuth, Syncthing (8300-8399)

STATE (Derived)
  ~/.local/state/nabi/ports/
    ├─ registry.json          ← Generated by transform_ports.py
    └─ manifest.json          ← Transformation audit trail
```

## Key Data Structures

### TOML (Human-Editable Config)

```toml
[services.loki]
port = 3100
protocol = "http"
purpose = "Federation event logging"
required = true
health_check = "/ready"
cross_platform = false

[services.loki.platforms.wsl]
enabled = true
port = 3101              # Platform-specific override
endpoint = "http://localhost:3101"
container_name = "federation-loki"
```

### JSON Registry (Machine-Readable)

```json
{
  "loki": {
    "port": 3100,
    "protocol": "http",
    "purpose": "Federation event logging",
    "required": true,
    "platforms": {
      "wsl": {
        "enabled": true,
        "port": 3101,
        "endpoint": "http://localhost:3101"
      }
    }
  }
}
```

## Rust Commands

| Command | Purpose | Notes |
|---------|---------|-------|
| `nabi port list [--platform PLATFORM]` | List allocations | Shows all services, optionally filtered |
| `nabi port check` | Validate vs running procs | Checks required services are listening |
| `nabi port cross-platform` | Check multi-platform conflicts | Detects drift from standards |
| `nabi port shift SERVICE OLD NEW [--dry-run]` | Migrate service port | Dry-run only, no execution |
| `nabi port drift [--forensic] [--since TIME]` | Analyze port drift | Shows migration notes & issues |
| `nabi port fix` | Auto-generate fixes | Outputs docker stop/start commands |
| `nabi port generate-env` | Generate .env for docker-compose | Creates .env.ports in cwd |

## Python Scripts (Manual)

```bash
# Transform TOML → JSON
python ~/.local/state/nabi/ports/../../../config/nabi/ports/../transform_ports.py
# OR from nabi-cli dir:
python src/ports/transform_ports.py

# Validate against running processes
python src/ports/validate_ports.py [--show-running] [--report]
```

## Platform Support

Detected automatically from system:
- **macos**: Darwin
- **wsl**: Linux + Microsoft in /proc/version
- **rpi**: Linux + Raspberry in /proc/cpuinfo
- **linux**: Generic Linux

## Port Ranges

| Category | Range | Preferred Host | Purpose |
|----------|-------|-----------------|---------|
| Infrastructure | 3000-3999 | rpi | Loki, Grafana, monitoring |
| Federation Core | 8000-8099 | cross-platform | MCP, coordination |
| Applications | 8100-8199 | single | Vigil, dashboards |
| Storage | 8200-8299 | cross-platform | SurrealDB, Redis |
| Communication | 8300-8399 | cross-platform | OAuth, Syncthing |
| Development | 8400-8499 | single | Local dev servers |

## Workflow

1. **Edit TOML**
   ```bash
   vim ~/.config/nabi/ports/communication.toml
   ```

2. **Transform to Registry**
   ```bash
   python ~/.local/state/nabi/ports/../../../config/nabi/ports/../transform_ports.py
   ```

3. **Validate**
   ```bash
   nabi port check
   python src/ports/validate_ports.py
   ```

4. **Check Cross-Platform**
   ```bash
   nabi port cross-platform
   ```

## Platform Override Examples

### Intentional Drift (Expected)

```toml
# Standard port
[services.loki]
port = 3100

# WSL uses different port for isolation
[services.loki.platforms.wsl]
port = 3101

# RPi exposes via external port
[services.grafana.platforms.rpi]
port = 3003          # External
container_port = 3000  # Internal
```

### Cross-Platform Service

```toml
[services.memchain_mcp_sse]
port = 8001
protocol = "http+sse"
required = true
cross_platform = true  # All platforms use same port

[services.memchain_mcp_sse.platforms.macos]
enabled = true
endpoint = "http://localhost:8001/sse"

[services.memchain_mcp_sse.platforms.wsl]
enabled = true
endpoint = "http://localhost:8001/sse"
```

## Architecture Pattern

Follows **Aura pattern**:
```
Config (TOML)  →  Transform (Python)  →  Derived State (JSON)  →  Runtime (Rust)
                   + Validation              + Manifest
```

- **Config Layer**: Source of truth (user-editable)
- **Transform**: Validate, resolve overrides, generate JSON
- **Derived State**: Fast, validated, structured
- **Runtime**: Read-only commands, no feedback to TOML
